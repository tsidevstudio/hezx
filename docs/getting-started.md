# Getting Started with HEZX

HEZX helps users evaluate purchases by tracking how often something is used and understanding its effective cost over time.

## General workflow

1. Install and open HEZX.
2. Follow the on-screen setup or first-use flow.
3. Add or configure the information relevant to your use case.
4. Review the result before relying on, exporting or sharing it.
5. Use the support channel below if something does not behave as expected.
