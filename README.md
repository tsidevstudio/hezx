# HEZX

**Price-per-use Tracker for Android**

HEZX helps users evaluate purchases by tracking how often something is used and understanding its effective cost over time.

## What it does

- Track purchases and their usage
- Follow effective price-per-use over time
- Keep personal usage records organized
- Backup and restore supported data
- Local-first workflow where practical

## Product principles

- Simple value tracking
- Local control where practical
- No unnecessary account requirement
- Focused Android utility
