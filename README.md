# HEZX

HEZX is an Android price-per-use tracker designed to help users understand the real value they get from the things they buy.

Instead of looking only at the purchase price, HEZX helps track usage over time and calculate how much an item effectively costs each time it is used.

## What HEZX does

- Track purchased items
- Record purchase price
- Track how often an item is used
- Calculate price per use
- Follow cost-per-use changes over time
- Compare value between different purchases
- Keep usage history organized
- Backup and restore data
- Local-first approach
- No unnecessary account requirement

## Price per use

HEZX is built around a simple idea:

**Purchase price ÷ number of uses = price per use**

As an item is used more often, its effective cost per use decreases.

This makes it easier to evaluate purchases based on actual usage rather than purchase price alone.

## Privacy approach

HEZX is designed around user control and practical local data management.

The app focuses on:

- Local-first usage
- No unnecessary accounts
- Minimal data collection
- No unnecessary cloud dependence
- User-controlled backups
